# UBKIR — Unbreakable Idea Research

Website oficial da UBKIR (Unbreakable Idea Research).

## Desenvolvimento local

```sh
npm install
npm run dev
```

## Build de produção

```sh
npm run build
```

Os ficheiros gerados ficam em `dist/` e podem ser carregados para o servidor (LusoAloja).

## Tecnologias

- Vite
- React + TypeScript
- Tailwind CSS
- shadcn/ui
